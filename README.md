# WhatsApp Translation Bot (Any → English)

Instructions:
1. Open this repo in GitHub Codespaces.
2. Edit `.env` with your GROQ_API_KEY and confirm MODEL.
3. In the Codespaces terminal run `npm install` then `npm start`.
4. Scan the QR code shown in the terminal with the WhatsApp account you want the bot to use.
5. Add that WhatsApp account to the group `TESTGROUP`.
6. Send messages in any language (non-English) — the bot will post the English translation. If message is already English the bot will do nothing.
